# Star Developers Technologies Pvt. Limited

Premium futuristic corporate website for a B2B IT company, built with Vite and a custom dark/light theme.

## Quick start

1. Install dependencies:
   npm install
2. Start the local dev server:
   npm run dev
3. Open the site in your browser at:
   http://localhost:3000

## Production build

npm run build

## Admin dashboard

Open:

http://localhost:3000/admin.html

The project estimator and contact form save entry data to the browser's localStorage, which can be reviewed from the admin dashboard.

## Project structure

- index.html – main landing page
- admin.html – lead dashboard
- src/main.js – landing page interactions and configurator logic
- src/admin.js – admin dashboard rendering logic
- src/styles.css – complete styling and 3D theme
- package.json – Vite scripts and dependencies
